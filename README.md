# LC3

**An offline-first Android music player built with Kotlin and Jetpack Compose.**

LC3 is an Android music player project focused on delivering a clean, intuitive and customisable listening experience for people who prefer playing music stored locally on their devices.

## Features

- Now Playing interface
- Album artwork display
- Playback controls UI
- Interactive playback progress slider
- Material 3 interface

## Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Design System:** Material 3
- **Build System:** Gradle
- **Platform:** Android

## Project Status

🚧 **Early Development**

LC3 is currently under active development. The initial focus is on building the user interface and establishing the application's structure.

## Planned Features

- Local music library scanning
- Audio playback using Android Media3
- Album and artist organisation
- Playlist management
- Shuffle and repeat
- Queue management
- Dynamic themes based on album artwork
- Offline-first functionality

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sungjimus/LC3.git
cd LC3
```

Build the debug APK:

```bash
./gradlew assembleDebug
```

The generated APK can be found at:

```text
app/build/outputs/apk/debug/app-debug.apk
```
